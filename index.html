The suite

  • seams-core

    v2.14.0. The seams CLI on the C++ engine: cages, CHILL+, topology keys, ions, guests, and per-atom dumps for OVITO or VMD. Language bindings are released separately from the engine.

    docs

  • pydseamslib

    pip install pydseamslib; import pydseams. Latest on PyPI is 2.11.1, for Python 3.11 or newer. Frame API, features for deeptime and PyEMMA, ion and guest helpers, pydseams.adapters for MDAnalysis and OVITO.

    book

  • yodaStruct

    Lua and Fennel. require("dseams"). Latest tag is v2.10.0. Build it from source; it is not on LuaRocks yet.

    book

  • R, Julia, Rust, Fortran

    dseams-r, Dseams.jl, dseams-rs and dseams-fortran call the engine through its C ABI. dseams-rs is on crates.io as the dseams crate at 2.14.0. dseams-r installs from GitHub and is not on CRAN yet. Dseams.jl is not in the Julia General registry yet.

  • dseams-plumed

    v0.4.0. The DSEAMS_CAGES PLUMED action: cage counts, ion classes, key libraries and filled cages on the fly.

  • linkcell

    Periodic linked-cell k-nearest neighbours for Rust, C, C++, and Python.

  • readcon-core

    CON and convel reader and writer for atomistic checkpoints, maintained under lode-org.

Call it

Install the Python wheel with pip install pydseamslib; the import remains pydseams. The latest wheel on PyPI is 2.11.1, built for Linux and Apple-silicon macOS on Python 3.11 or newer. Build the seams CLI and the C libraries from source with meson, pixi or Nix. libseams is not on conda-forge yet. The seams CLI commands are read, chill, chill-plus, ovito-chill+, cages, symmetry, rings, prisms, cluster, fingerprint, ions, f4, steinhardt, rdf, cn, hbonds, pairs, density-z, and domains.

Two classifiers

CHILL+

Four-neighbour star. Labels cubic, hexagonal, interfacial, clathrate, and water. It does not assign cage membership.

Cages

Hexagonal cages (HC) are ice Ih. Double-diamond cages (DDC) are ice Ic. Everything else is water on that score.
