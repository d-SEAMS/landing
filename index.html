Molecular dynamics - Ice, clathrates & rings

Classify ice and cages in MD trajectories.

One C++ engine (seams-core) has native bindings across Python, Rust, Julia, R, Lua, Fortran, and PLUMED. Use the CHILL+ local-structure algorithm to label ice phases. Isolate hexagonal and double-diamond cages, and trace primitive rings.

Install & run Read engine docs

Reads LAMMPS, GROMACS, OpenMM, the .xyz format, and .con via readcon-core; adapters support MDAnalysis, Open Visualization Tool (OVITO), and ASE.

Python (pydseamslib)

Frame API, NumPy arrays, Steinhardt features, and adapters for MDAnalysis, OVITO, and ASE.

Open Python book 
pip install pydseamslib
import pydseams as ds

frame = ds.read("water.lammpstrj")
print(frame.chill_plus())

Rust (dseams)

Safe handles, typed options structs, and zero-overhead access to CHILL+, rings, and cages.

Open Rust book 
cargo add dseams --features bundled
let (xyz, edge) = seams::diamond8();
let mut system = seams::System::new()?;
system.set_ortho(&xyz, edge, edge, edge)?;
let ice = system.chill_plus(&seams::ChillOptions::default())?;

Self-contained R interface returning data frames and tables for CHILL+ labels and ring histograms.

Scriptable Lua and Fennel module over the engine workflows via require("dseams").

Libraries - Standalone neighbour search

linkcell

d-SEAMS uses linkcell for neighbour search, but it stands alone as an independent library.

Periodic kNN and cutoff pair lists (linkcell)

Periodic linked-cell k-nearest neighbours and cutoff pair lists for orthogonal and triclinic cells, in Rust, C, C++, and Python, usable on its own.

Open linkcell book 
pip install linkcell numpy
cargo add linkcell
import linkcell, numpy as np
xyz = np.array([[0.2, 0.0, 0.0], [9.4, 0.0, 0.0]])
cell = np.array([10.0, 10.0, 10.0])
nn, d2 = linkcell.knearest(xyz, cell, 1)

linkcell and vesin

linkcell is a drop-in replacement for vesin with the same i, j, S layout. NeighborList.compute takes points, the cell, periodic, and quantities.

Minimum image & cells vesin repo
vesin linkcell
Answers who is inside radius r. Does cutoff pair lists (pairs_within, in the same i, j, S layout), and also answers who are the k nearest with the periodic image without a cutoff by growing shells until the k-th neighbour is certified.
Python NeighborList and C libvesin.so. Python linkcell.NeighborList(cutoff, full_list, ...) returning i, j, P, S, d, D, and C include/linkcell_vesin.h with vesin's struct layout and lc_vesin_neighbors.
Handles non-periodic axes and CUDA devices as well as periodic CPU boxes. Builds fully periodic CPU lists itself, and forwards a non-periodic axis or a CUDA device to libvesin.so when that library is present. 
# Swap `from vesin import NeighborList` for:
from linkcell import NeighborList
import numpy as np

xyz = np.array([[0.2, 0.0, 0.0], [9.4, 0.0, 0.0]])
box = np.diag([10.0, 10.0, 10.0])
i, j, S, d = NeighborList(cutoff=1.5, full_list=True, sorted=True).compute(
    xyz, box, periodic=True, quantities="ijSd"
)
